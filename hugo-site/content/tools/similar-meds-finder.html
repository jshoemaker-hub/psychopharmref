Psychopharmacology

Find Similar Medications: Switching After Poop-Out

Rank psychiatric drugs by pharmacologic similarity to one that stopped working, using receptor binding, action, class, indications, and residual symptoms.

Open Find Similar Medications

Runs free in your browser. Rankings are calculated on your device and not sent to a server.

What it does

When a medication that once worked best loses its effect (tachyphylaxis, or "poop-out"), this tool lists the agents in the PsychoPharmRef database with the most similar pharmacology, as a starting point for a switch. Select the reference medication and the tool ranks the others by percent match, six at a time, with a button to show the next six. You can restrict results to the same category, filter by route (oral, long-acting injectable, intramuscular, or intravenous), and tick residual symptoms that the new agent should still cover.

How similarity is scored

Each candidate is compared with the reference on up to six axes, and you can adjust the weight of each with a slider:

AxisWhat it comparesDefault weight
Receptor bindingCosine similarity of the two drugs' binding profiles (pKi above a floor of 5, which is Ki 10,000 nM)60
Action matchWhether both drugs do the same thing (for example both antagonists) at receptors both bind with pKi ≥ 615
Cascade-tier matchAgreement in the level of signal transduction10
Class matchSame class scores 100%, same category 50%25
Shared indicationsOverlap in FDA indications15
Symptom coverageWhether the candidate's mechanism plausibly covers the ticked residual symptoms30

Any axis that cannot be measured for a pair is dropped, and the remaining weights are rescaled to sum to 100%. Residual symptom options are insomnia, anhedonia, anxiety, cognition or inattention, agitation, psychotic symptoms, poor appetite, sexual dysfunction, and somatic pain. Candidates whose mechanism may worsen a ticked symptom are flagged.

What the report includes

Each result card explains the match. The copyable summary lists the date, the reference drug, any route and symptom filters, and for each candidate the overall match, the per-axis scores, available routes, shared receptor targets, receptors with the same or a different action, symptom coverage and "may worsen" flags, and shared indications. A receptor comparison table is shown when the reference has binding data.

Limitations

Pharmacologic similarity does not guarantee comparable efficacy or tolerability in an individual patient. For apparent tachyphylaxis the tool advises first reassessing adherence, dosing, substance use, and the diagnosis. Some patients do better with a switch to a different mechanism or with augmentation; the companion Find Complementary tool covers that question.
