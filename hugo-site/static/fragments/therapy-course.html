Educational use — This course supports supervised skill development. It does not replace formal training, certification, or clinical supervision, and the interactive worksheets are teaching aids, not validated instruments.

What this course does

Most therapy training explains what a treatment is. This course focuses on how to run it: structuring sessions, assigning and reviewing homework, troubleshooting the moments where technique breaks down, and tracking outcomes. Each module pairs a concise didactic “how-to” with interactive worksheets and goal-setting tools you can use in session or in role-play.

Course learning objectives

By the end, participants will be able to: conduct functional assessments and build individualized formulations; deliver key techniques of each therapy with high fidelity; structure sessions and manage homework; adapt protocols for age, development, comorbidity, culture, and setting; select and use outcome measures; and recognize when to refer or combine approaches (including with medication).
