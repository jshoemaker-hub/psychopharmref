## 1. Measurement

### What is on the live site

The only measurement ID in templates and in live HTML is `G-RK6J3FQ9L7` (`ga4ID` in `hugo-site/hugo.toml`).

| Page type | Live tag | Config calls |

`ga-init.js` exists so the config can live in a file. The content-security policy has no `'unsafe-inline'` for scripts. Loading `gtag/js?id=` and then one `gtag('config')` is the same install snippet Google documents, split across a file. On the 215 tagged sitemap URLs that pair appears once. A text search also hits strings such as `G-CSF` and `G-PET` inside chapter prose. Those are not tags.

Repo copies under `blog/*.html` still contain an inline `gtag('config', 'G-RK6J3FQ9L7')`. Those files are not what Netlify publishes. `https://psychopharmref.com/blog/schizophrenia.html` returns **301** to `/blog/schizophrenia/`, and that URL's HTML is the Hugo page (one external tag, no inline config). There was no live duplicate to remove. The preview copies were left as they are so a local open of `blog/<slug>.html` still has its own tag.

### Change in this PR

Handouts, `/privacy.html`, `/legal-disclaimer.html`, and the new editorial page each get the same one external tag and no inline config. After deploy, the 51 previously untagged indexable URLs (plus the editorial page) should show one `gtag/js` and one `ga-init.js`.

### Broken internal links

All 266 sitemap URLs were fetched and their same-site links were checked without following redirects.

- 96 unique URLs returned **404**. The pattern is a chapter that still linked to `other-chapter.html`. Hugo publishes the chapter at `/blog/<slug>/`, so the browser requested `/blog/<slug>/other-chapter.html`. Examples: `/blog/domestic-violence/geriatric-psychiatry.html`, `/blog/low-energy-fatigue-workup/insomnia.html`, `/blog/blog/medical-psychiatry-interface.html` (from `../blog/...` on the psychosomatic chapter).

- `/privacy` and `/legal-disclaimer` (extensionless) returned 200, as did extensionless handout URLs. Those are the duplicates above, not 404s.

This PR rewrites chapter links in `hugo-site/content/` to `/blog/<slug>/`, and share URLs that still pointed at `.html` (including percent-encoded ones) to the same canonical. Three links pointed at chapters that are not in the repo (`neurobiological-basis-of-psychiatric-illness`, `medical-psychiatry-interface`, `trauma-neurobiology`). A redirect `/blog/:slug/:file.html` → `/blog/:file/` remains so an old nested URL still resolves after deploy. It is a one-hop 301, not a chain.

`/handouts/` (no file) is 404. Handouts are linked as individual files and from `/#handouts` on the homepage. No index was added.

## 3. Titles and meta descriptions

Rendered `<title>` length follows the Hugo rule in `baseof.html`: `seoTitle` if set, otherwise `title`, and ` - PsychoPharmRef` only when that string is 43 characters or shorter. Against current front matter, **zero** rendered titles exceed 60 characters. The homepage title is 60 characters. No title was rewritten.

Two live titles looked longer than 60 only because an HTML parser also collected SVG `<title>` elements (clock-drawing test, antipsychotic review). The real `<title>` elements are `The Clock-Drawing Test: Patterns and Scoring` and `Antipsychotic Medications: A Clinical Review`.

Meta descriptions existed on every sitemap URL except `/offline.html` (noindex, not in the sitemap). Many were weak:

- 47 chapter descriptions began with a space (the summary inherited indentation).
- 105 contained an ellipsis. Hugo's `truncate` adds that when `description` is empty and `.Summary` is cut at 155 characters.
- The only duplicated description was the homepage sentence, repeated because `/`, `/index.html`, and `http://www…` are the same document.

Empty `description` fields remain on **41** chapters. Their meta description is still the truncated summary. This PR fills or tightens descriptions only where a priority chapter was truncated, using the page's own scope (the 16 student chapters named in `CLAUDE.md`, minus PTSD, which already ended on a full sentence):

- New `description` on schizophrenia, bipolar disorder, major depression, both medication reviews, delirium, alcohol use disorder, panic/GAD, serotonin syndrome/NMS, suicide risk assessment, and capacity.
- Shortened, still accurate, descriptions on the learning-tools, psychiatric interview, adult ADHD, and emergency psychiatry chapters so they no longer end in an ellipsis.

Hub descriptions were already full sentences: `/blog/` ("Evidence-based clinical chapters…"), `/tools/`, `/news/`, and `/tools/drug-database/`. The chapter index now falls back to the summary when a card's description is empty, so those cards are not blank.

`og:description` previously ran `truncate` without `plainify`, so the antipsychotic review JSON-LD description on the live site included a raw `<div class="ba-lead">`. Meta and Open Graph descriptions in `baseof.html` now plainify and trim whitespace first.
